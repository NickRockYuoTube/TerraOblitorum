=====================================================
  ШПАРГАЛКА: ОФОРМЛЕНИЕ ЗАПИСОК (BBCode в Godot)
=====================================================

Где писать: ресурс записки (NoteData) -> поле Text.
Тег открывается [тег] и закрывается [/тег].
Всё, что между ними, получает оформление.


-----------------------------------------------------
  ОСНОВНОЕ
-----------------------------------------------------

[b]текст[/b]                    жирный
[i]текст[/i]                    курсив
[u]текст[/u]                    подчёркнутый
[s]текст[/s]                    зачёркнутый

[color=red]текст[/color]        цвет по названию (red, yellow, gray, white...)
[color=#8b0000]текст[/color]    цвет по HEX-коду (точнее)

[font_size=28]текст[/font_size] размер шрифта

[center]текст[/center]          по центру
[right]текст[/right]            по правому краю


-----------------------------------------------------
  ЭФФЕКТЫ ДЛЯ ХОРРОРА
-----------------------------------------------------

[shake rate=20 level=5]текст[/shake]
    текст дрожит (трясущаяся рука)
    rate  — скорость дрожи
    level — сила дрожи

[wave amp=30 freq=3]текст[/wave]
    текст плавно колышется
    amp  — высота волны
    freq — частота волны

[fade start=0 length=20]текст[/fade]
    текст постепенно растворяется
    start  — с какого символа начинается затухание
    length — на сколько символов растягивается


-----------------------------------------------------
  КОМБИНИРОВАНИЕ ТЕГОВ
-----------------------------------------------------

Закрывать теги нужно в ОБРАТНОМ порядке:

[color=#8b0000][shake rate=25 level=8]ОНО ЗДЕСЬ[/shake][/color]

  открыли: color -> shake
  закрыли: shake -> color


-----------------------------------------------------
  МЕЛОЧИ
-----------------------------------------------------

Перенос строки       — обычный Enter прямо в поле текста
Квадратная скобка [  — пиши [lb]
Квадратная скобка ]  — пиши [rb]

Картинка в тексте:
[img=200]res://assets/photo.png[/img]
    200 — ширина картинки в пикселях
    (для одной картинки к записке удобнее поле Image)


-----------------------------------------------------
  ПОЛЕЗНЫЕ ЦВЕТА
-----------------------------------------------------

#8b0000   тёмно-красный (кровь, опасность, коды)
#d4a017   тёмно-жёлтый  (важные предметы)
#4a6fa5   приглушённый синий (места, комнаты)
#7a7a7a   серый (стёртый, выцветший текст)
#2e5e2e   тёмно-зелёный (безопасное, лекарства)


-----------------------------------------------------
  СОВЕТ ПО ДИЗАЙНУ
-----------------------------------------------------

Выделяй цветом только то, что важно для прохождения,
и всегда ОДНИМ И ТЕМ ЖЕ цветом. Например:

  жёлтый  — предметы
  красный — коды и опасность
  синий   — места

Игрок быстро привыкнет и начнёт сам искать подсказки глазами.


-----------------------------------------------------
  ПРИМЕР ЗАПИСКИ (можно скопировать целиком)
-----------------------------------------------------

[center][b]14 октября[/b][/center]

Генератор снова барахлит. Чтобы его запустить, нужен [color=#d4a017][b]предохранитель[/b][/color] — запасной лежит где-то в [b]мастерской[/b].

Код от шкафчика: [color=#8b0000][b]4 - 7 - 1[/b][/color]
Не забудь его снова, идиот.

[i]Кто-то ходит по подвалу по ночам. Я слышу шаги прямо под полом.[/i]

[s]Завтра поговорю с начальником.[/s]
[color=#8b0000][shake rate=25 level=6]НЕ СПУСКАЙСЯ ВНИЗ[/shake][/color]
